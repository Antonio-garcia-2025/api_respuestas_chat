# Chat Response API

**English** | [Español](#api-de-respuestas-de-chat)

REST API built with FastAPI that receives a text message, detects the user's intent with an NLP model (TF-IDF + Logistic Regression), and returns a predefined response. Designed as a customer-support chatbot for an online store.

## Tech Stack

Python 3, FastAPI, Uvicorn, scikit-learn, Pydantic

## Project Structure

```
api_respuestas_chat/
├── main.py            # FastAPI app (/predecir endpoint)
├── train.py           # Model training
├── test.py            # Test script
├── intents.json       # Intents, patterns and responses
├── modelo_nlp.pkl     # Trained model (generated by train.py)
├── vectorizador.pkl   # TF-IDF vectorizer (generated by train.py)
└── requirements.txt   # Dependencies
```

## Installation

```bash
git clone https://github.com/Antonio-garcia-2025/api_respuestas_chat.git
cd api_respuestas_chat
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Usage

Start the server:

```bash
uvicorn main:app --reload
```

Interactive docs are available at `http://127.0.0.1:8000/docs`.

### `POST /predecir`

Request:

```json
{ "texto": "cuanto cuesta el envio" }
```

Response:

```json
{
  "respuesta": "Realizamos envíos a todo el país. ...",
  "intencion": "envios"
}
```

If the model's confidence is too low, the API asks the user to be more specific.

## Customizing Intents

1. Add a new block to `intents.json` with a `tag`, `patterns` and `responses`.
2. Retrain the model: `python train.py`
3. Restart the API.

Available intents: `saludos`, `despedidas`, `horarios`, `envios`, `carrito`, `contacto_humano`, `consultar_catalogo`.

# API de Respuestas de Chat

[English](#chat-response-api) | **Español**

API REST construida con FastAPI que recibe un mensaje de texto, detecta la intención del usuario mediante un modelo de NLP (TF-IDF + Regresión Logística) y devuelve una respuesta predefinida. Diseñada como chatbot de atención al cliente para una tienda en línea.
